Frequently Asked Questions (FAQ)

Q: Who can participate in SMCC-CCIS Week?

Registration URL Encoding Example

When submitting form data via URL, spaces are encoded as %20:

https://www.smccnasipit.edu.ph/register?name=Juan%20Dela%20Cruz&course=BSIT§ion=A

In this URL, %20 represents a space in URL encoding. Special characters like &, =, and ? have specific meanings in URLs.

HTML vs XHTML Syntax Comparison

HTML5

<br>
<img src="images/logo.png" alt="Event Logo">
<input type="text" required>
<meta charset="UTF-8">

XHTML

<br />
<img src="images/logo.png" alt="Event Logo" />
<input type="text" required="required" />
<meta charset="UTF-8" />

XHTML requires all elements to be properly closed, attributes to be quoted, and tags to be in lowercase. HTML5 is more forgiving and allows self-closing tags without the trailing slash.
